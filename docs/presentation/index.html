System Architecture
Strict Backend Abstraction & MCP Interface
Architecture
  • React 18 UI: Fast modern single-page app with TanStack Query, dark/light theme, and SSE streaming AI panel.
  • FastAPI REST + FastMCP: Exposes 14 standard tools for part search, BOM explosion, compare, and blast-radius analysis.
  • Decoupled PLMBackend: All tools call `PLMBackend` interface only. Zero SQLite or Windchill imports in tool code.
  • Dynamic Backend Switch: Driven by `PLM_BACKEND=mock` (SQLite) or `PLM_BACKEND=windchill` (PTC OData).
🎙️ "By adhering strictly to the Adapter pattern, our tools, AI agents, and UI screens remain 100% agnostic to whether the backend is SQLite or PTC Windchill."

Enterprise Safety
Two-Step Safety Gate & Cardinality Guardrails
Safety & Governance
  • Two-Step Safety Gate: AI agents can only generate drafts. Modifying production baselines requires explicit `confirm=True`.
  • Metric Cardinality Guard: Part numbers (`PMP-0010`) are quarantined as OpenTelemetry span attributes, NEVER metric labels.
  • Prompt Redaction: Proprietary geometry and specifications are masked (`[REDACTED]`) by default via `OTEL_CAPTURE_PROMPTS=false`.
  • Zero-PII Client Scrubber: Automatically scrubs auth headers, passwords, and user emails before telemetry is emitted.
🎙️ "We designed ThreadMind so it cannot corrupt a database. Hallucinated parameters are rejected by Pydantic; write actions are locked behind human sign-off."
